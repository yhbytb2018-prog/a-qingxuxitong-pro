# 双轨披露框架（V5.2 主信号 + V5.3 风险参考线）

- 状态：**规格草案（Draft，待审）**——本文档只定义机制与字段，未动任何生产代码
- 依据：`tools/backtest/experiment_dual_track.mjs`（双门禁绿：E0↔v52、FULL↔v53 对账吻合）
- 前序裁决：终极 PK（V5.3 = 定价合理的保险，非免费午餐）→ 本框架回答"保险怎么买"

## 一、实证基础（为什么是这三条轨道）

介入矩阵实测（241 交易日全样本，保费 = E0 收益 − 变体收益，保额 = E0 回撤 − 变体回撤）：

| 介入方案 | 总收益 | 保费 | 最大回撤 | 保额 | 样本外夏普 | 判定 |
|---|---|---|---|---|---|---|
| E0 不介入（纯 V5.2） | -1.50% | — | 13.79% | — | +0.390 | 主信号基线 |
| T2 深尾两档（ice+ebb 帽0.2） | -5.86% | 4.36pp | 13.44% | 0.35pp | — | **证伪** |
| T3 尾部三档（+shift 帽0.3） | -3.04% | 1.54pp | 12.72% | 1.07pp | +0.091 | **证伪** |
| T1 仅切换期（shift 帽0.3/0.4） | -0.68% / +0.02% | **-0.82 / -1.52pp（净增益）** | 14.03% / 13.61% | -0.24 / -0.18pp | **+0.419 / +0.427** | 唯一正贡献候选 |
| FULL 全量切换（=V5.3-A） | -3.71% | 2.21pp | 8.78% | 5.01pp | -0.211 | 整份保险（PK 已裁） |

三条硬结论：

1. **尾部介入是亏本保险，证伪**。用户直觉方案（"V5.3 风险信号触发时临时介入"）的尾部档版本：保费 > 保额（T2 4.36→0.35、T3 1.54→1.07）。根因：V5.3 的 5pp 保额**不来自尾部档**——回撤窗（2026-06-22→09-28，70 日）内 FULL 亏 -8.99% vs T3 -12.98% vs E0 -13.58%，保额 80% 来自 recover/neutral 0.5 帽在慢跌全程压仓；而样本内 4 段急跌全是 V 型，T+1 下尾部帽只会割在反弹上（T2 窗内 -13.81%，比不介入还差）。**保额与保费（40~50 段 -3.55pp 伤害）是同一机制的捆绑包：没有"只买尾部"的选项。**
2. **T1（切换期次日帽）是唯一正贡献候选**。归因分解：帽生效日 18 天合计 **+2.70pp（结构性）**——shift = 判据矛盾覆盖（假繁荣背离/高潮末段），次日避险有真实预报价值；非生效日 -1.87pp（重建滞后+成本+路径级联）。帽值 0.2~0.6 全区间符号一致为正（+0.75~+2.70pp），样本外夏普不降反升（0.419/0.427 > 0.390）。**但**：仅 18 个生效日、量级对帽值敏感、级联拖累近七成——按 M8/M2 尸检纪律，不直接执行。
3. **所以正确形态 = 披露 + 影子**：V5.3 整线作参考披露（不执行）；shift 次日帽作影子介入（记账不执行），P2 积累样本后走晋升门禁。

## 二、轨道定义

```
轨道 A（执行层）  V5.2 主信号
  · scoreWith + positions 四档阈值（24/44/65/80），maxPosChg=0.2 平滑，stopLoss/ddTrigger 原样
  · 唯一真实执行轨道；P2 模拟的资金曲线 = 轨道 A
轨道 B（参考层）  V5.3-A 风险参考线
  · 轨道 A + regime 全量帽（ice/ebb 0.2、shift 0.3、recover/neutral 0.5、climax 1.0）
  · 每日计算、逐日披露、永不执行；作用 = "若整份买保险，今天会在哪"
  · 备注：confirmDays 在指数轮动口径下为 no-op（全年 3 次开仓，确认门从未触发），
    参考线实现时取 0 即可，不影响任何数字（扰动检验零变化佐证）
轨道 C（候选介入层）  shift 次日帽 —— 影子执行
  · 规则：若 T 日 regime = shift（判据矛盾覆盖），则 T+1 日仓位帽 = C（影子同时记
    C ∈ {0.3, 0.4, 0.5} 三条线——影子零成本，一次性把决策区间全记上）
  · 仅记账：每日记录"若执行会怎样"，不动轨道 A 的任何仓位
```

## 三、每日披露字段（规格）

```jsonc
// signals 侧新增块（名称暂定 dualTrack；实现路径见第五节，P2 期间先由旁路工具产出）
{
  "date": "2026-10-09",
  "regime": { "key": "shift", "label": "切换期", "cap": 0.3,
              "reasons": ["水位×宽度背离：假繁荣嫌疑", "高潮末段特征"] },
  "trackA": { "targetPos": { "asset1": 0.7, "...": 0 }, "poolPos": 0.63, "executed": true },
  "trackB": { "refPos":    { "asset1": 0.3, "...": 0 }, "poolPos": 0.27, "executed": false },
  "divergence": { "posGap": 0.36,          // trackA.poolPos − trackB.poolPos
                  "note": "分歧=保险当日保费敞口" },
  "trackC": { "active": true,              // 前一日 regime === 'shift'
              "shadowPos": { "0.3": 0.30, "0.4": 0.40, "0.5": 0.50 },
              "biting": { "0.3": true, "0.4": true, "0.5": false } },  // 是否真压到轨道A
  "ledger": {                    // 保险账本（P2 起累计，日更）
    "since": "2026-10-09",
    "premiumCum": 0.0212,        // Σ(A日收益 − B日收益)：整份保险累计保费
    "coverageCum": 0.0188,       // (A回撤 − B回撤)：累计保额（回撤差口径，日更）
    "shadowCum": { "0.3": 0.004, "0.4": 0.006, "0.5": 0.009 },  // Σ(A − C) 影子累计增益
    "shadowEpisodes": 3          // 影子生效日计数（晋升门槛的分母）
  }
}
```

披露口径三原则（与既有纪律同源）：

- **缺失显式化**：regime=unknown 时 trackB 帽按保守档 0.2 计（CONSERVATIVE_BAND），并在 divergence.note 标注"状态缺失，参考线按保守档"；
- **数字唯一出处**：帽值只引用 `POSITION_BANDS`，本框架不自造数字；轨道 C 的 {0.3,0.4,0.5} 为实验扫描区间，晋升前不得收窄；
- **免责声明**：轨道 B/C 均为风控参考，不是买卖信号（沿用 `DISCLAIMER` 口径）。

## 四、影子账本与晋升门禁（轨道 C 转执行的唯一通道）

晋升条件（全部满足才可提案，提案后仍走 `scripts/promote_params.mjs` 样本外门禁 + `experiment_boost_stress.mjs` 残差压力测试）：

1. **样本量**：P2 影子生效日累计 ≥ 10（全样本历史仅 18 日/年，按当前频率约 3~6 个月攒齐）；
2. **方向一致性**：三条影子线（0.3/0.4/0.5）累计增益同号——若符号分裂，判为帽值敏感的过拟合，整案废弃；
3. **结构占比**：生效日贡献 / 净增益 ≥ 50%（归因分解口径同实验⑧；防止路径级联伪装成 alpha）；
4. **残差纪律**：生效日后 5 日内最大额外仓位 ≤ 0.05（帽是压仓语义，天然满足——但必须留门禁记录）。

回滚设计：轨道 C 关闭 = 纯 V5.2，无状态迁移、无残留仓位（与动量加速尸检的"触发关闭≠残差关闭"教训相反，压仓类规则的退出天然干净——这恰是 T1 可候选而 M8 不可候选的工程理由之一）。

## 六、与 P2 观察清单的衔接

- 清单第一节"仓位残差监控"：`divergence.posGap` 即其数据源（阈值沿用：>2% 告警、>3% 暂停调仓排查）；

- 清单第十节 Go/No-Go："监控告警通道打通"的前置实现 = P2-α 的日频 JSON。

## 附：裁决一句话

双轨不是"二选一替换"，也不是"保险信号临时介入"（尾部介入已证伪）——是 **V5.2 独跑 + V5.3 全程陪跑披露 + shift 次日帽影子记账**。保险明码标价每日可见，候选规则证据攒够再谈执行。
