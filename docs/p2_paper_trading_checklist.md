## 系统现状基线

- **V5.2（基础版）**：0.2 平滑机制，全样本（241 交易日，上涨日 50.6%）收益 -1.50%，跑赢基准池（-2.53%）与 HS300（-6.10%），最大回撤 13.79%（基准池 19.31%）。核心 Alpha 来源 = 满仓区（65~80 分）+6.27% 超额。
- **V5.3-A（Regime 机制版）**：回撤控制优异（8.78%），收益偏低（-3.71%）。终极 PK 结论：保险档而非免费升级——保费 2.21pp 收益 + 样本外夏普 0.6，保额回撤减 5pp + 参数敏感度减半；确认门在指数轮动口径下为 no-op，其个性 100% 来自 regime 帽。
- **已证伪方案（不得回流）**：动量加速 M8（仓位残差延迟爆炸、满仓崩盘日多扛 0.07 仓位）；0.7 分区帽（完整样本收益 -1.50% → -2.28%）。

## 一、仓位残差监控（P0 级）

动量加速（M8）尸检表明：触发条件关闭 ≠ 仓位残差关闭。加速抬高的仓位经平滑残差埋入后续行情，在满仓大跌日兑现亏损。

| 监控项 | 阈值/正常范围 | 异常动作/警戒线 |
|---|---|---|
| 目标仓位 vs 实际仓位偏差 | 偏差 ≤ 1% | 偏差 > 2% 触发告警；> 3% 暂停调仓并排查平滑模块 |
| 平滑后仓位残差绝对值 | 残差 ≤ 0.5% | 残差 > 1% 触发告警；连续 3 日残差同向累积 > 2% 强制归零 |
| 加速类钩子状态 | 全部禁用（OFF） | 任意钩子状态为 ON，立即停机并回滚配置 |
| 仓位变化日频幅度 | 单日调仓幅度 ≤ 5% | 单日调仓 > 8% 触发人工复核；> 10% 自动拦截并告警 |
| 残差累积周期 | 残差应在 5 个交易日内收敛至 0 | 超过 7 个交易日残差未收敛，触发模块级诊断 |

## 八、极端行情应急流程

### 8.1 熔断/跌停场景

| 触发条件 | 应急动作 | 恢复条件 |
|---|---|---|
| 持仓标的跌停 | 暂停该标的买入，评估卖出可行性 | 跌停打开且流动性恢复 |
| 大盘单日跌幅 > 5% | 触发 V5.3-A 风险态，仓位降至 30% 以下 | 连续 3 日企稳且 Regime 确认恢复态 |
| 连续 3 日跌幅 > 10% | 全面暂停调仓，人工介入评估 | 市场情绪指标恢复正常 |

### 8.2 系统故障场景

| 触发条件 | 应急动作 | 恢复条件 |
|---|---|---|
| 信号生成服务宕机 | 维持当前仓位，禁止新开仓 | 服务恢复且信号验证通过 |
| 订单执行服务宕机 | 切换备用执行通道 | 主通道恢复并完成压力测试 |
| 数据源中断 | 使用缓存数据，暂停调仓 | 数据源恢复且数据完整性校验通过 |

### 8.3 资金风控底线

| 触发条件 | 应急动作 | 恢复条件 |
|---|---|---|

## 附录：关键术语速查

| 术语 | 解释 |
|---|---|
| Regime | 市场状态识别机制，通过状态切换自动调节仓位均值，以应对不同市场环境 |
| 平滑系数 | 用于平滑仓位变化的参数，0.2 表示仓位调整幅度为理论值的 20%，以降低交易频率与冲击成本 |
| 仓位残差 | 目标仓位与实际仓位之间的偏差，通常由平滑机制或执行延迟导致，需持续监控以防累积风险 |
| Alpha | 策略超越基准收益的部分，反映策略的选股或择时能力 |
| Beta | 策略对市场整体波动的敏感度，反映系统性风险暴露 |
| 夏普比率 | 风险调整后收益指标，计算公式为（策略收益 - 无风险收益）/ 策略波动率 |
| 卡玛比率 | 收益回撤比指标，计算公式为策略年化收益 / 最大回撤，衡量单位回撤下的收益能力 |
| 回测伪影 | 回测中因数据、逻辑或执行假设不合理导致的虚假收益或风险，需在实盘中验证并排除 |
| 样本外门禁 | 用于验证策略在未见数据上表现稳定性的测试集，通过门禁方可进入实盘 |
| 尸检 | 对策略失败或异常表现的深度复盘分析，旨在定位根因并制定修复方案 |
