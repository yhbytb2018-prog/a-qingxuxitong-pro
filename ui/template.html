状态代表个股

归集口径：某交易日的状态由当日及此前几日的情绪分按上方规则逐日判定；个股净买为该状态内全部交易日龙虎榜净额求和（全榜营业部口径），按绝对值排序代表「资金最活跃」。代表 ≠ 推荐——退潮/冰点期的高位净卖个股同样是重要信号。

判定规则 五状态 · 位置 + 趋势 + 拐点 = 仓位依据

状态判定条件常见思路（经验参考，非操作指令）
❄ 冰点区情绪分 < 30统计上是中线「分批区域」：分批、慢买、买超跌不买强势；忌追当日热点
📈 回升期30~65 且近 3 日累升 ≥ 4 分顺势跟随主流题材，仓位随情绪抬升逐步放大；做强于大盘的票胜率相对高
➖ 中性区45~55 震荡、方向不明降低频率——震荡市频繁交易是散户最大亏损来源，适合做功课等方向
🔥 偏热区情绪分 > 65持仓黄金期但不宜新开重仓；盯见顶前兆：炸板率跳升、净买转负
🌧 退潮期近 5 日曾有 >65 高点，且近 3 日累跌 ≥ 4 分收缩仓位、停做接力；翻历史回看页找上次退潮见底特征，写好冰点应对计划
叠加预警（任何状态自动检查）：偏热 + 龙虎榜净买 < 0 → 诱多风险；炸板率 > 30% → 接力恶化；冰点 + 净买 > 0 → 转折观察。本模块为统计口径的方法演示，不构成投资建议。
数据来源：东方财富·数据中心「龙虎榜」(RPT_DAILYBILLBOARD_DETAILSNEW)；同花顺·热点强势股题材归因(zx.10jqka.com.cn)；同花顺·行业指数日K(d.10jqka.com.cn, 881xxx 板块涨跌榜与 5 日动量由日K重建；原东财 push2his 对本机 IP 受限后切换)；腾讯·指数与个股日K(web.ifzq.gtimg.cn)。
系统口径（合并版 · PRO 管线）：仅含真实交易日（交易日历由上证指数日K反推，休市日自动剔除；回填占位日不入页面）；每日快照由 PRO 管道入库（盘前六源真实冒烟 CI 门禁 → 非交易日/已入档幂等跳过 → freshness 落盘）；情绪指数七因子 = 龙虎榜净买20%+净买家数比10%+行业广度20%+题材热度10%+涨跌停对比15%+封板质量10%+量能15%（因子缺失按代理/中性补位并显式留痕 emotion.missing）；龙虎榜双口径：当日榜 lhb_daily_*（权威）/全量 lhb_all_net（诊断），同股多榜五元组合并、新股与区间榜显式标记（is_range）；题材经词典归一+孤点剔除（themeList 含强度分）；分位为在全部存档日中的排名（防前视：分位窗口锁前置窗口）；外推=近10点最小二乘线性回归延后3个交易日；点击任意股票查看个股详情（K线走势/上榜历史/题材归因+资金画像，全离线）。实验室：个人数据（权重口径/预测/哨兵/笔记）仅存本机浏览器 localStorage，不上传；实时条：腾讯指数+东财涨停池 JSONP 直连，交易时段 30s 轮询，盘外显示最近收盘快照。生成时间 __BUILD_AT__ · 存档 个交易日。
